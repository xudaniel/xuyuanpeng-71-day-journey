# 71-Day OS

一个面向手机使用的个人行程与执行管理工具，将日常安排、出行确认、会前准备和后续跟进集中在一个地方。

## 应用入口

| 入口 | 用途 | 访问方式 |
| --- | --- | --- |
| [分享版](https://xudaniel.github.io/xuyuanpeng-71-day-journey/) | 查看获授权分享的安排 | 输入访问密码 |
| [完整版](https://xudaniel.github.io/xuyuanpeng-71-day-journey/private.html) | 查看详细安排 | 输入独立访问密码 |
| [手机 OS](https://xudaniel.github.io/xuyuanpeng-71-day-journey/os.html) | 管理优先事项、出行确认与跟进 | 使用当前设备的保险库密码 |

访问密码由资料所有者另行提供。

## 可以做什么

- **今日重点**：按 P0 / P1 / P2 查看优先事项和提醒。
- **出行确认**：记录交通与住宿的确认状态，检查时间冲突和转场间隔。
- **会前准备**：快速查看准备进度，在详情页补充检查项。
- **会后跟进**：整理笔记、下一步行动与等待回复的事项。
- **进度管理**：区分计划、实际完成和待核验状态。
- **备份与恢复**：导出加密备份，在需要时恢复本机记录。

## 使用方式

1. 从上方选择入口，并使用对应密码解锁。
2. 在手机 OS 中记录个人事项，按需补充准备信息、确认依据及后续行动。
3. 定期导出加密备份，妥善保管备份和密码。

手机 OS 的个人记录保存在当前浏览器，以本机密码加密。设备之间通过备份与恢复迁移数据。分享版、完整版与本机保险库使用各自的密码入口。

## 项目说明

本项目通过 GitHub Pages 提供静态页面。密码入口保护对应页面中的加密内容；仓库中的其他文件和历史版本仍按仓库可见性访问。

README 仅用于介绍功能与入口。维护本页时，不添加实际行程日期、城市路线、当前位置、参访对象、交通住宿细节或行程变更摘要，也不嵌入行程截图、概览图或明文行程资料链接。
