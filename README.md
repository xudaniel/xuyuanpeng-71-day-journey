## 三个使用场景

1. **看行程**：先看当前城市与下一站，再打开对应阶段；完整接待和交通安排沿用完整版。
2. **做准备**：每家企业一张卡，先明确参访目的，再从三个问题中选出最重要的一个。
3. **留成果**：参访后记录事实、个人判断和下一步，不把提问草稿写成对方的回答。
