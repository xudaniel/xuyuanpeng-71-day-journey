# 徐远鹏先生｜七十一日行程

面向移动端设计的行程进度与执行看板。项目采用“公开安全分享版＋加密完整版”的双层结构，在便于查看与转发的同时，尽量减少敏感信息暴露。

## 版本说明

| 版本 | 入口 | 适用场景 | 信息范围 |
| --- | --- | --- | --- |
| 手机安全分享版 | `index.html` | 日常查看、对外转发 | 仅展示概览与脱敏内容 |
| 加密完整版 | `private.html` | 本人及授权人员使用 | 输入访问密码后，在浏览器本地解密完整行程 |

GitHub Pages 入口：

- 公开入口：<https://xudaniel.github.io/xuyuanpeng-71-day-journey/>
- 完整版入口：<https://xudaniel.github.io/xuyuanpeng-71-day-journey/private.html>

访问密码不会写入本仓库，也不应通过公开渠道发送。

## 核心功能

### 每日秘书简报

- 根据北京时间自动定位当天，并支持按自然日查看前一天或后一天。
- 首屏展示当天城市、执行事项、下一行动、接待协调、地点、建议出发及准备事项。
- 完整版支持复制地点和打开地图；安全版保持相关信息隐藏。
- 可单独导出当天日历：有明确时刻的事项附带提前30分钟提醒，未确定时刻的事项按全天事件处理。

### 71天进度与执行提醒

- 分别显示时间进度和人工核验进度，避免把“日期已经过去”误认为“执行已经完成”。
- 自动计算当前是第几天、当前阶段、剩余天数及下一次转场。
- 已结束但未核验的阶段标记为“逾期待核验”，并提供专门筛选。
- 核验状态保存在当前设备，可随时标记或取消。

## 安全设计

- 完整行程使用 **AES-256-GCM** 加密。
- 密钥由访问密码通过 **PBKDF2-SHA-256（310,000 次迭代）** 派生。
- 解密仅在访问者的浏览器内完成，页面不会上传或保存密码。
- 公开版已移除确认号、交通班次、详细地址、联系人及其他敏感明文。
- 页面不依赖后台数据库，不设置账户，不包含统计追踪代码。

## 使用与维护

1. 对外只分享公开入口。
2. 完整版链接与访问密码应分开传递。
3. 行程内容发生变化时，应重新生成安全版和加密密文。
4. 怀疑密码泄露时，应立即更换密码并重新加密发布。
5. 更新前检查源码，确认敏感信息没有以明文形式出现。

## 重要限制

本项目的密码页属于浏览器端加密访问，不等同于服务器账户系统。公开 GitHub 仓库的历史提交仍可能保留过去发布过的内容；如需彻底移除旧敏感资料，必须另行清理 Git 历史、旧部署及相关缓存。

`main` 分支由 GitHub Pages 发布；新功能应先通过 PR 审阅。
