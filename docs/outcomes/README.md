## 填写规则

1. 将“计划日期”和“实际完成日期”分开；只有获得实际记录后才标记已完成。
2. 把对方陈述、现场观察、个人判断分栏；关键结论附材料或出处。
3. 每项下一步使用独立编号，写明行动、负责人、目标日期及状态；没有约定就不填“已承诺”。
4. 日期统一为“2026年9月11日（周五）”形式；有时刻时标明时区。
5. 机构页保留纪要，[统一跟进清单](follow-ups.md)汇总行动；不要把同一行动拆成两份互相冲突的记录。
